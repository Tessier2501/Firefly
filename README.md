## 4. 调试工作方式

- 一次只改一个变量；记录旧值、新值、写入者、时间、生效条件、观测效果；没有预期效果先回滚。
- 定位根因时逐段测量：命令 → 计算输出 → 串口/电气输出 → 执行器响应 → 物理效果。
- 不要关闭安全/健康/解锁门禁；“能启动”不是健康指标。
- 能独立隔离的组件，先在其边界直接取 ground truth，再换件或改配置。
- 不把派生/融合遥测当作物理事实；需要直接测量或做受控扰动。
- 设备用序列号、UID、物理拓扑定位，不用 COM 号或 Windows 显示名。
- 台架安全：拆桨/卸负载，断电接线，首次限流上电，按官方图片核对针序，禁止反灌电源。
- 接受残余风险时，记录理由、缓解措施和重新评估触发条件。

## 5. 记忆与交接

- 长期事实与决策统一放在 Memory Space 账本 `Firefly Ledger`。
- 根目录不创建 `FACT.md` / `DECISION.md` / `CURRENT.md` / `ARCHITECTURE.md` / `OPERATIONS.md`。
- 事实条目用 `FACT-<slug>`，决策条目用 `DEC-<slug>`；每条都带来源、观测时间和复查条件。
- Agent 只提出 `MEMORY DELTA`，由人工审核后手动写入；禁止自动写入。
- 新 agent 接手必须先输出 `HANDOFF BRIEF`，再开始修改。
- 详细协议见 `AGENTS.md`。
