# data

调试数据与分析产物，按机架独立存放；除 `AGENTS.md` 外不纳入 git。

## 1. 结构

```text
data/
|-- AGENTS.md
`-- frame_<ID>/
```

- 机架 ID 格式为 `<YYYY_MM_DD>_<NN>`：格式无实际意义，仅视为标识符。
- ID 定下后不再修改；换件、重复调试不改 ID。
- 机架 ID 不是设备身份：飞控、电调、电台按序列号 / UID 区分。

## 2. 文件

- 文件名格式 `<YYYY_MM_DD_HHMM>_<主题>.<扩展名>`，时间戳取采集开始时刻。
- 原始采集只增不改；分析产物可重新生成；笔记中过时或已无用信息果断删除。
